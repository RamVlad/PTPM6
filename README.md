# PTPM6 — Калькулятор стоимости тетрадей

Проект для практической работы №6 по дисциплине «Поддержка и тестирование программных модулей».

## Описание

Калькулятор рассчитывает стоимость заказа тетрадей с обложками по формуле:
**Итого = (цена_тетради + цена_обложки) × количество**

## Структура проекта

- `calculator.py` — чистая функция расчёта (без GUI)
- `uchebnaia.py` — графический интерфейс (Tkinter)
- `tests/test_calculator.py` — модульные тесты (pytest)
- `.github/workflows/main.yml` — автоматический запуск тестов через GitHub Actions

## Запуск тестов локально

```bash
pip install -r requirements.txt
python -m pytest tests/ -v
